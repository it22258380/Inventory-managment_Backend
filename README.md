# Inventory-managment_Backend
Backend for Inventory managment

Project Overview 

This Inventory Management System is a web-based application designed to manage inventory 
for retail shop called “daily-mart”. This system efficiently track, manage, and update their 
product inventory in real-time. It allows users to add new items, update stock levels, monitor 
sales, and analysis, ensuring accurate and streamlined inventory control.. The goal is to minimize 
human error, save time, and provide businesses with reliable insights for better decision-making. 

Features list 
• User can add ,view ,update and delete inventory items. 
• User can view analytical details such as catogeries,counts and low stock alert. 

Technologies 
• Tech stack-MERN(Mongo DB ,Express Js ,React JS ,Node js) 
• Frontend (React):  Create a responsive UI using React (Tailwind CSS). 
• Backend (Node.js + Express):  Build REST API endpoints 
• Database (MongoDB) 
• Git hub-version controlling 
• Postman-Validate Backend endpoints 
• Wireframes- Mockflow 
• Visual code- Development Environment (IDE)
